### Задание 1

```cpp
#include <iostream>

int main() {
    int a = 42;                 // десятичный
    int b = 052;                // восьмеричный
    int c = 0b101010;           // двоичный
    int d = 0x2A;               // шестнадцатеричный

    unsigned int e = 42U;       // unsigned
    long f = 42L;               // long
    unsigned long g = 42UL;     // unsigned long
    long long h = 42LL;          // long long
    unsigned long long i = 42ULL;

    std::cout << a << ' ' << b << ' ' << c << ' ' << d << '\n';
    std::cout << e << ' ' << f << ' ' << g << ' ' << h << ' ' << i << '\n';

    return 0;
}
```

### Задание 2

```cpp
char a = 'a';
a = a + 10;
std::cout << a;
a = a + 250;
std::cout << a;
```

Используем коды символов ASCII:

- `'a'` = 97 = `0b01100001`;
- `97 + 10 = 107`, а код 107 — это `'k'`;
- затем `107 + 250 = 357`.

В `char` длиной 1 байт значение хранится по модулю 2^8 = 256:

357 mod 256 = 101

Код 101 — символ `'e'`.

Поэтому программа выводит:

```text
ke
```

Первый символ появляется из обычного сложения кодов, а второй — после переполнения `char`.

### Задание 3

```python
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')

a = chr(ord(a) + 250)
print(a, end='')
```

Результат:

```text
kť
```

Почему результат отличается от C++:

- в C++ `char` имеет фиксированную разрядность, поэтому после `357` происходит переполнение 8-битного значения: `357 mod 256 = 101`;
- в Python `int` имеет произвольную длину, поэтому значение `357` не переполняется;
- `chr(357)` возвращает Unicode-символ с кодом 357 — `ť`.
